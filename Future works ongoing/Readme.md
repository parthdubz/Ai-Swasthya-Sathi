# Project Status

## ✅ Currently Working

### 1. **Trained LLM (Fine-tuned)**
- Custom fine-tuned language model optimized for Nepali + English health awareness responses
- Model configured to follow the strict 4-sentence health response format:
  - Empathy (सहानुभूति)
  - General causes (सामान्य कारणहरू)
  - Self-care tips (स्वयं-हेरचाह)
  - Reassurance + professional nudge (आश्वासन र सल्लाह)
- Maintains safe boundaries: no diagnosis, no medication recommendations, no clinical procedures
- Handles mixed Nepali-English input naturally with appropriate code-switching

### 2. **React JS App**

- Supports both Nepali and English input seamlessly
- Clean, intuitive UI for health-conscious users
- Real-time message handling and response display
- Mobile-friendly responsive design
